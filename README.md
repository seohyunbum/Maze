# 🌀 손으로 그리는 미로

### ▶️ 지금 바로 하기 — https://seohyunbum.github.io/Maze/

링크만 있으면 친구도 바로 할 수 있습니다. 로그인도, 앱스토어도 필요 없습니다.

### 📱 휴대폰에 앱으로 설치하기

위 링크를 휴대폰 브라우저로 열면 **설치 안내가 아래에서 저절로 올라옵니다.**

- **안드로이드(크롬)** — **설치하기** 한 번이면 끝
- **아이폰(사파리)** — 아래쪽 공유 버튼 → **홈 화면에 추가**
  (아이폰은 브라우저가 설치 기능을 열어주지 않아 이 두 단계가 필요합니다.
   크롬으로 열면 아예 안 되니 사파리로 열어주세요 — 앱이 알려줍니다.)

설치하면 홈 화면에 아이콘이 생기고, 주소창 없는 전체 화면으로 열립니다.
**인터넷이 없어도 실행됩니다** — 비행기 모드나 지하철에서도 됩니다.

## 규칙

- 초록색 **시작**(왼쪽 위)에서 손가락이나 마우스로 끌어 빨간색 **도착**(오른쪽 아래)까지 가면 통과!
- 손이 지나간 자리는 **검은색 선**으로 그려집니다.
- **검은색 벽은 넘어갈 수 없습니다.** 벽에 닿으면 거기서 멈춥니다.

## 기능

- 난이도 4단계 (10×10 / 16×16 / 22×22 / 28×28) — 고를 때마다 새 미로 생성
- `새 미로` 새로 만들기 · `다시 그리기` 선만 지우기 · `정답 보기` 힌트 경로 표시
- 걸린 시간과 난이도별 최고기록 저장, 벽에 막힌 횟수 표시
- 화면 비율에 맞춰 미로 모양이 정해짐 — 세로 휴대폰이면 세로로 긴 미로로 화면을 꽉 채움
- 손가락으로 그을 수 있도록 칸 크기를 확보 (너무 작아지면 미로를 자동으로 줄임)
- 밝은/어두운 화면 모두 대응, 노치·홈 인디케이터 회피

미로는 매번 새로 만들어지며 **항상 풀 수 있는 미로**만 생성됩니다.
만들 때마다 후보를 40개 만들어 그중 가장 헷갈리는 미로 하나만 골라 씁니다 —
정답이 짧거나 갈림길이 없는 싱거운 미로는 나오지 않습니다.

## 배포

`main` 에 푸시하면 GitHub Pages 가 자동으로 다시 배포한다
(Settings → Pages → Deploy from a branch → main / (root)).
의존성이 없는 단일 HTML 파일이라 빌드 단계가 없다. `.nojekyll` 은 Jekyll 처리를 끈다.

**게임을 고쳐 배포할 때는 `sw.js` 의 `CACHE` 버전을 반드시 올릴 것.**
안 올리면 이미 설치한 사람에게 예전 화면이 계속 보인다.
